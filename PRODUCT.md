# Product

## Platform

web

## Stack
Shopify Online Store 2.0 theme (draft theme «Fecha Estelar · Viaje Cósmico (borrador)», ID 211900858693, built from Horizon). Home uses its own layout `fe-cosmos` and `fe-*` sections; product, cart and checkout use the Horizon layout. Three.js + GSAP ScrollTrigger + Lenis from jsDelivr (version-pinned import map). Heavy media (frame packs, NASA textures) served from this public GitHub repo via jsDelivr — confirmed by the owner.

## Users
Couples aged 25–45 in Spain buying an emotional gift (anniversaries, weddings, births, Valentine's Day, Christmas, remembrance). ~80 % arrive on mobile.

## Product Purpose
A printed lámina (poster) with the real star map of a chosen date, time and place, personalised with names and a phrase. Success = a visitor understands it in seconds, designs their own and buys without friction.

## Positioning
The sky is calculated, not decorative: real star positions from astronomical catalogues (Hipparcos / Yale Bright Star via d3-celestial) for the exact date, hour and city.

## Operating Context
Personalisation app: Customall (its app block goes in the «FE · Creador» section). Print and fulfilment: Printful. Guest checkout (no account).

## Product Principles
1. Show the real thing: every sky on the page is computed.
2. Price, free shipping and the buy action are never more than a glance away.
3. Emotion first, but no fake urgency or fake proof.
4. Mobile is the main stage; desktop is the cinema.

## Accessibility & Inclusion
Respect prefers-reduced-motion with a still, composed alternative. WCAG AA contrast. Real buttons and labels; editable alt text.
